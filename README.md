# เกรียนออนไลน์ — GRIAN ONLINE

MMORPG แฟนตาซีล้อเลียนเกมดัง เล่นได้ในเบราว์เซอร์ ไม่ต้องติดตั้งไลบรารีภายนอก
โลก 3D (three.js Procedural 3D Architecture & Props) + พิกเซลอาร์ต 2D · เนื้อหาภาษาไทย · **รองรับระบบออนไลน์เรียลไทม์ (Multiplayer)**

> **v2.0.0** — เปิดระบบออนไลน์จริง (WebSocket + SSE Multiplayer) · ยกระดับกราฟิก 3D (บ้าน 3D / ต้นไม้ 3D / ตู้เซิร์ฟเวอร์ 3D / เสาไฟ 3D / ออร่า 3D / สไปรต์ถืออาวุธประจำคลาส) · ระบบชุดเกราะครบ 3 ช่อง + โบนัสเซ็ต · บอสโลกครบทั้ง 3 โซน · พร้อมไฟล์ Deploy ขึ้นคลาวด์ทันที

---

## 🌐 วิธีเปิดเซิร์ฟเวอร์ออนไลน์ (Deploy ขึ้น Cloud / เล่นกับเพื่อน)

โปรเจกต์ใช้เฉพาะโมดูลมาตรฐานของ Node.js (**Zero npm dependencies**) จึงรันได้ทันทีทุกที่:

### 1. รันในเครื่องหรือ VPS
```bash
node serve.mjs          # เปิดที่ http://127.0.0.1:8731 (พร้อม WebSocket /ws และ /api/*)
# หรือเปิดให้เครื่องอื่นในวงแลน/อินเทอร์เน็ตเข้าได้:
PORT=8731 node serve.mjs
```

### 2. เปิดออนไลน์ฟรีบน Render.com / Railway / Fly.io / Docker
ในโฟลเดอร์มีไฟล์ `package.json`, `Dockerfile` และ `render.yaml` เตรียมไว้ให้ครบแล้ว:
- **Render.com**: เชื่อมต่อ GitHub repo `akaradje/grian-online` → เลือก **New Web Service** (ระบบจะอ่าน `render.yaml` และรัน `node serve.mjs` อัตโนมัติ พร้อม Health Check ที่ `/api/health`)
- **Railway.app**: กด **Deploy from GitHub repo** → ออนไลน์ได้ทันทีโดยไม่ต้องตั้งค่าเพิ่ม
- **Docker**:
  ```bash
  docker build -t grian-online .
  docker run -p 8731:8731 grian-online
  ```

## 🚀 ไฮไลต์อัปเดตใหญ่ใน v2.0.0

### 1. ระบบออนไลน์เรียลไทม์ (Real-Time Multiplayer — `serve.mjs` & `public/js/net.js`)
- **Native WebSocket (`/ws`) + HTTP/SSE Fallback (`/api/stream`, `/api/sync`, `/api/chat`, `/api/action`, `/api/status`)**:
  - ผู้เล่นทุกคนที่เปิดเว็บเข้าสู่เซิร์ฟเวอร์เดียวกันจะมองเห็นตัวละครของผู้เล่นอื่นเดิน ตีมอน ใช้สกิล และแสดงวงออร่าตีบวกแบบเรียลไทม์พร้อมป้ายชื่อ **`🌐 [ชื่อผู้เล่น]`**
  - **แชทออนไลน์ข้ามเครื่อง**: พิมพ์แชทในช่องโลก/ปาร์ตี้/ซื้อขาย ข้อความจะเด้งขึ้นที่หน้าจอของผู้เล่นทุกคนในเซิร์ฟเวอร์ทันที
  - **PK / สกิลข้ามเครื่อง**: เมื่อเปิดโหมด PK สามารถโจมตีและเห็นเอฟเฟกต์สกิลของผู้เล่นออนไลน์คนอื่นในแมพเดียวกันได้สดๆ

### 2. ยกระดับกราฟิก 3D & สไปรต์ตัวละครครั้งใหญ่ (`gfx3d.js`, `sprites.js`)
- **โมเดลสถาปัตยกรรมและพร็อพ 3D จริง (`_build3DArchitecture`)**:
  - **บ้านในหมู่บ้าน 3D**: ผนังอิฐ/ไม้ 3D, หน้าต่างเรืองแสงไฟอุ่น 3D, ประตูไม้ 3D และหลังคากระเบื้องทรงจั่ว 3D เต็มหลังที่ทอดเงาจริงลงบนพื้น
  - **ต้นไม้ & หิน 3D**: ลำต้นไม้ทรงกระบอก + พุ่มใบทรงกรวย 2 ชั้น และโขดหินรูปทรงเรขาคณิต 3D
  - **เสาไฟถนน 3D · บ่อน้ำ 3D · รูปปั้น 3D · หีบสมบัติ 3D · ประตูมิติ 3D Torus หมุนวน**
  - **ตู้แร็คเซิร์ฟเวอร์ 3D (`CYBERTREE`) & แท่นขุดการ์ดจอ 3D (`CYBERROCK`)** ในโซนที่ 3 พร้อมแผงไฟสถานะ LED เรืองแสง
- **อบพื้น 3D สะอาด (`bakeCleanGround3D`) + GLSL Micro-Detail Shader**:
  - แยกแคนวาสพื้นสำหรับโหมด 3D ไม่ให้มีภาพต้นไม้/เสาไฟ/หีบ 2D แบนๆ ติดอยู่ใต้โมเดล 3D
  - เพิ่มรายละเอียดพื้นผิวใน Fragment Shader (คลื่นน้ำ Caustics, เส้นวงจรไซเบอร์วิ่งเป็นจังหวะ, ลาวาแมกมาเรืองแสง)
- **วงแหวนออร่า 3D ใต้เท้า (`auraPool`)**: แสดงวงแหวนเวท 3D หมุนและกะพริบตามจังหวะใต้เท้าผู้เล่นที่ตีบวก `+5 / +7 / +9 / +10` และมอนสเตอร์ระดับ Elite/Boss
- **สไปรต์ตัวละครละเอียดสูงพร้อมอาวุธประจำคลาส + Pre-Flipped `FrontSide` Cache**:
  - วาดไฮไลต์ทรงผม แววตา 2 ชั้น ผ้าคลุม เกราะไหล่ เข็มขัดทอง และอาวุธในมือแยกตามอาชีพ (ดาบเงิน, คทาไฟ, มีดคู่, ดาบไซเบอร์ RGB, เรเปียร์ทอง, ค้อนแบนแอดมิน)
  - ใช้ทริคพลิกซ้าย-ขวาที่แคนวาสใน `_frameTex(sprId, frame, flip)` ทำให้ใช้ `THREE.FrontSide` ได้ตลอดเวลาโดยตัวหันซ้ายไม่หายและได้ FPS สูงสุด

### 3. ระบบเกมเพลย์ RPG สมบูรณ์พร้อมเล่น (`data.js`, `entities.js`, `systems.js`, `ui.js`)
- **อุปกรณ์สวมใส่ครบ 3 ช่อง (`อาวุธ · ชุดเกราะ · เครื่องประดับ`) + โบนัสเซ็ต**:
  - เพิ่มชุดเกราะใหม่ 4 ระดับ: **เสื้อยืดแถมงานเกม (XL)**, **เสื้อกันหนาวร้านเน็ต**, **เกราะกระดูกไฟนรก**, และ **เกราะ RGB สุลต่านไซเบอร์**
  - ตีบวกได้ครบทั้ง 3 ช่อง (`+1` ถึง `+10`) และเมื่อสวมใส่อุปกรณ์ครบทั้ง 3 ช่องจะได้รับ **✨ โบนัสเซ็ตครบชุด (MaxHP +10% · ATK +10% · DEF +5)**
- **บอสโลกประจำโซนครบทั้ง 3 แมพ**:
  - แมพ 1 (`field`): **ครูฝึกสอนการบ้าน** (Lv.15)
  - แมพ 2 (`hell`): **พญามารทวงหนี้นอกระบบ** (Lv.22 · ดรอปเกราะกระดูกไฟนรก)
  - แมพ 3 (`cyber`): **AI แอดมินคลั่ง GPT-999** (Lv.30 · ดรอปเกราะ RGB สุลต่านไซเบอร์ & ดาบเลเซอร์)
- **ร้านค้า NPC ขยายคลังสินค้า + คลิกบนมินิแมปเพื่อเดินอัตโนมัติ (Minimap Click-to-Move)**

## ทดสอบอัตโนมัติ (`tools/smoke.mjs`)

`tools/smoke.mjs` ทดสอบทุกระบบใน Chromium จริง **86 ข้อ** (รวมทดสอบ Multiplayer API/Sync, โบนัสเซ็ต 3 ชิ้น, 3D Architecture Meshes, ออร่า 4 ขั้น และยศ PvP 5 ระดับ) ผ่านทั้งหมด `console error = 0`:

```bash
node serve.mjs 8731 &
node tools/smoke.mjs 8731
```
