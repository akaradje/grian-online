# เกรียนออนไลน์ — GRIAN ONLINE

MMORPG แฟนตาซีล้อเลียนเกมดัง เล่นได้ในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร
พิกเซลอาร์ต 2D + โลก 3D (three.js) · เนื้อหาภาษาไทย · **ไม่มี asset ภายนอกแม้ไฟล์เดียว** (รวมเสียง)

> **v1.0.1** — แก้บั๊กรอย Seriously เรนเดอเรอร์ 3D (พื้นไม่เป็นกำแพงไทล์ตั้งฉาก · ตัวละครหันซ้ายไม่หาย · พื้นตรงพิกัดโลก · ลาวาเรืองแสงถูกที่ · prop cutout โปร่งใส) + เทสต์ PvP 5 ยศ/ออร่า 4 ขั้น (85/85)

> **v1.0.0** — แมพโซน 3 (แดนเซิร์ฟเถื่อน) · ปาร์ตี้บอท & บัฟกิลด์ · ดันเจี้ยนหอคอยบั๊ก · PvP โหมดหัวแดง · ตีบวกขั้นสูง + ยันต์กันแตก + ออร่าอาวุธ · เอฟเฟกต์สกิล 3D & ซูมกล้อง · แก้บั๊กฟิสิกส์/3D ครบ

## 🚀 อัปเดตใหญ่ใน v1.0.0 (ครบทั้ง 4 ด้าน)

### 1. คอนเทนต์และมุกใหม่ (`data.js`, `sprites.js`, `world.js`, `audio.js`)
- **🌐 แมพโซนที่ 3 — "แดนเซิร์ฟเถื่อน" (`mapId: 'cyber'`, seed `2077`)**:
  - เดินทางผ่านประตู Portal จากดินแดนมาร หรือกดวาร์ปด่วนในหน้าต่าง **ปาร์ตี้ & ประลอง (`V`)**
  - ไทล์ใหม่ 5 ชนิด: พื้นแผงวงจรไซเบอร์ (`CYBERFLOOR`), สายธารดาต้าเรืองแสง (`DATASTREAM`), ตู้แร็คเซิร์ฟเวอร์เถื่อน (`CYBERTREE`), แท่นขุดการ์ดจอ (`CYBERROCK`), และ **บ่อบั๊กไฟดูด (`GLITCH`)** ที่ช็อตผู้เล่นต่อเนื่อง 8 ดาเมจ/วินาที
  - เพลงประกอบใหม่ **Cyber Synthwave 8-bit** (136 BPM) สังเคราะห์สดด้วย WebAudio
- **👾 มอนสเตอร์ใหม่ 3 ตัว (จับเป็นสัตว์เลี้ยงได้ครบทุกตัว — รวม 10 สายพันธุ์)**:
  - **บอทขุดเหรียญ (`botmon`)** — บอทปล่อยบอทตีมอนอีกทอด ดรอปการ์ดจอไหม้เกรียม
  - **ตัวบั๊กทะลุแมพ (`glitchbug`)** — มอนที่นักพัฒนาลืมลบ ดรอปหินอัพเกรดและยันต์กันแตก
  - **สุลต่านสายเปย์ (`whale`)** — วาฬใส่แว่นทอง ฟาดด้วยสลิปบัตรเครดิต ดรอปป้ายสุลต่าน VIP 99 และดาบไฟไซเบอร์ RGB
- **🧑‍💻 NPC และเควสต์เนื้อเรื่องใหม่ 3 เควสต์**:
  - NPC ใหม่ **"เด็กฝึกงานแก้บั๊ก" (`dev_intern`)** ประจำแดนเซิร์ฟเถื่อน พร้อมบทสนทนาล้อเลียนชีวิตโปรแกรมเมอร์
  - เควสต์ใหม่: **ปราบปีศาจไฟในดินแดนมาร** (`q_hell`), **กู้คืนการ์ดจอที่ไหม้เกรียม** (`q_gpu`), และ **กำจัดตัวบั๊กทะลุแมพ** (`q_glitch`)
- **🎁 ไอเทมล้อเลียนใหม่ 5 ชิ้น & ขยายตู้กาชา**:
  - **ดาบไฟไซเบอร์ RGB** (+42 ATK, มีไฟวิ่ง 16.8 ล้านสี), **ป้ายสุลต่าน VIP 99** (+28 ATK, +20% โชค), **ยันต์กันแตก (ของแท้ 99%)**, **การ์ดจอไหม้เกรียม**, และ **เครื่องดื่มชูกำลังคูณร้อย**

### 2. ขยายระบบเกมเพลย์ (`entities.js`, `ui.js`, `main.js`, `achievements.js`)
- **🤝 ระบบปาร์ตี้จำลอง & บัฟกิลด์ (กด `V`)**:
  - ชวนบอทในแมพเข้าปาร์ตี้ได้สูงสุด **3 คน** — บอทที่อยู่ในตี้จะเดินตามผู้เล่นและช่วยรุมตีมอนสเตอร์จริง พร้อมแชทปาร์ตี้และโบนัส **ATK +8% / EXP +15% ต่อสมาชิก 1 คน**
  - **บัฟกิลด์จำลอง**: บริจาคเงินกิลด์เพื่อรับบัฟ **ธงกิลด์จอมตีบวก (+20% ATK)**, **พรเทพเจ้าเกลือ (+35% อัตราดรอป)**, หรือ **สายแลนไฟเบอร์ออปติก (+25% ความเร็วเดิน)**
- **🔨 ระบบตีบวกอุปกรณ์ขั้นสูง + ยันต์กันแตก + ออร่าอาวุธ**:
  - ตีบวกอุปกรณ์ `+1` ถึง `+10` เพิ่มค่า **ATK / DEF / LUCK จริงทุกขั้น** (และโอนระดับตีบวกให้อัตโนมัติเมื่อสลับอุปกรณ์ชิ้นใหม่)
  - **ระบบหลอมยันต์กันแตก**: ใช้หินอัพเกรด 3 ก้อน + 500 เงิน หลอมเป็น **🧿 ยันต์กันแตก** ในหน้าต่างกระเป๋า (`I`) เมื่อตีบวก `+4` ขึ้นไปแล้วพลาด ระบบจะใช้ยันต์กันของแตกให้อัตโนมัติ
  - **ออร่าอาวุธตามระดับตีบวก**: ถึง `+7` ได้ **ออร่าฟ้า**, `+9` ได้ **ออร่าทอง**, และ `+10` ได้ **ออร่าม่วงราชันย์** หมุนรอบตัวละคร
- **🗼 ดันเจี้ยนไต่หอคอยบั๊ก (Endless Bug Tower)**:
  - กดท้าทายหอคอยบั๊กในหน้าต่าง `V` เพื่อเรียกมอนสเตอร์ระดับ Elite ออกมาเป็นเวฟตามชั้น ยิ่งชั้นสูงมอนยิ่งเยอะและเก่งขึ้น เคลียร์ครบรับรางวัลเงิน เพชร และรับ **ยันต์กันแตกฟรีทุกชั้นคู่**
- **🥊 ศึก PvP / โหมดหัวแดง (PK) กับบอทเกรียน**:
  - เปิดโหมด PK หรือกด **"ท้าดวลบอทที่ใกล้ที่สุด"** เพื่อปะทะกับบอทในแมพ บอทจะสวนกลับและพ่นประโยคแชทท้าทายเมื่อชนะ/แพ้
  - สะสมแต้มชนะ PvP เลื่อนยศตั้งแต่ `นักเลงคีย์บอร์ดฝึกหัด` → `นักเลงหน้าเซเว่น` → `ขาใหญ่ประจำร้านเกม` → `หัวแดงประจำเซิร์ฟ` → `ตำนานเกรียนไทย` (รับโบนัส ATK ถาวรตามยศ)
- **🏆 ความสำเร็จใหม่ 4 รายการ** (รวมทั้งหมด **32 รายการ**): `ทะลุมิติเซิร์ฟเถื่อน`, `นักเลงคีย์บอร์ด`, `ผู้พิชิตหอคอยบั๊ก`, และ `กันไว้ดีกว่าแก้`

### 3. อัปเกรดกราฟิก 3D และ UI/UX (`gfx3d.js`, `vfx.js`, `index.html`, `style.css`, `ui.js`)
- **🎥 ซูมกล้อง 3D (Camera Zoom)**: หมุนลูกกลิ้งเมาส์ (Mouse Wheel) เพื่อซูมกล้องเข้า-ออก (`0.65x` ถึง `1.40x`) ดูรายละเอียดฉากหรือขยายมุมมองกว้างได้อิสระ
- **✨ เอฟเฟกต์สกิล 3D จริง (3D Skill VFX Meshes)**: เมื่อร่ายสกิลในโหมด 3D จะสร้าง Mesh วงแหวนคลื่นกระแทก 3D (`Shockwave Ring`) และเสาแสง 3D (`Light Pillar`) บนพื้นโลกจริงควบคู่กับระบบ 2D VFX
- **🌈 Shader & แสงไฟโซน 3 ใน `gfx3d.js`**: เพิ่ม GLSL Shader สำหรับสายธารดาต้า (`DATASTREAM`) และบ่อบั๊กไฟดูด (`GLITCH`) พร้อมไฟ PointLight สีฟ้า/ม่วงไซเบอร์
- **📱 หน้าต่าง UI ใหม่ `#panel-social` (ปุ่ม `⚔️ V`)**: รวมปุ่มวาร์ปด่วน 3 โซน, โหมด PK, หอคอยบั๊ก, ปาร์ตี้บอท และบัฟกิลด์ไว้ในหน้าต่างเดียว รองรับทั้งหน้าจอเดสก์ท็อปและมือถือ

  js/fx.js              particle แบบ pool (+หิ่งห้อย/ละอองบรรยากาศ) · กล้อง · แสงกลางวัน-คืน · hit-stop · ตัววัดประสิทธิภาพ

  js/main.js            เกมลูป (fixed timestep 60Hz) ตัวเรนเดอร์ อินพุต + Portal 3 โซน + ลาว/บ่อบั๊กไฟดูด

serve.mjs               เซิร์ฟเวอร์ไฟล์นิ่งสำหรับรันในเครื่อง (เสิร์ฟ public/ เท่านั้น)
